# **App Name**: FixIt Connect

## Core Features:

- Homeowner Profiles: Allow homeowners to create profiles with their contact and location information.
- Specialist Profiles: Allow specialists to create profiles, detailing skills, certifications and contact details.
- Request Posting: Homeowners can post detailed repair or service requests with descriptions and images.
- Rate Estimation: An AI tool provides rate suggestions based on the type of request and other contributing factors.
- Offer Submission: Allow specialists to send offers with approximate fees via WhatsApp.
- WhatsApp Link: Streamline initial communication and provide users the option to transition to other means if desired.
- Login System: Login system for both homeowners and specialists

## Style Guidelines:

- Primary color: Pine green (#01796F) to evoke trust and reliability.
- Background color: Beige (#F5F5DC), providing a neutral and calming backdrop.
- Accent color: Gray (#808080) for a modern, professional touch, used in borders and secondary text.
- Body and headline font: 'PT Sans' for clear and friendly communication.
- Use clean, modern icons for categories, services, and profile options.
- Emphasize readability, scannability and ease of navigation.
